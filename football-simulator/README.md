# FUTBOL X — ультра-аркадный футбольный симулятор

Автономная браузерная игра для телефона: одним пальцем управляешь игроком,
бьёшь по воротам и открываешь суперспособности. Полностью на русском языке,
без сборки и зависимостей — чистые HTML/CSS/JS.

## Что внутри

- **Управление одним пальцем**: виртуальный джойстик слева, кнопка удара/паса
  справа (тап — пас, удержание — заряд удара, свайп вверх — навес).
- **Шкала ULTRA** и суперспособности: 🔥 Огненный неберущийся удар,
  ⏱️ Разрыв времени (замедляет соперника), 🧲 Магнит-дриблинг.
- **Мгновенный повтор гола** в slow-motion, как на большом телевидении.
- **Динамическая погода**: дождь, снег, ветер, ночные матчи — влияют на
  физику мяча и визуал поля.
- **Карьера**: лестница из 8 клубов Российской Ультра-Лиги с растущей
  сложностью.
- **Магазин и прогрессия**: монеты, опыт, уровни, формы, мячи, стадионы,
  способности — всё сохраняется в localStorage.
- **Достижения**, кастомизация клуба, звук на Web Audio API (без файлов),
  вибро-отклик и PWA (устанавливается на домашний экран, работает офлайн).

## Как запустить

Нужен любой статический HTTP-сервер (Service Worker и localStorage требуют
`http://`, не `file://`):

```bash
cd football-simulator
python3 -m http.server 8080
# затем открой http://localhost:8080 на телефоне или в мобильном режиме браузера
```

Либо `npx serve .` из этой папки.

## Структура

```
football-simulator/
├── index.html      — разметка всех экранов и HUD матча
├── css/style.css    — стили (тёмная тема, стекло, неон)
├── js/data.js       — статические данные: клубы, стадионы, магазин, ачивки
├── js/state.js      — сохранение прогресса в localStorage
├── js/audio.js      — синтезированные звуковые эффекты
├── js/game.js       — игровой движок: физика, ИИ, рендер, повторы
├── js/ui.js         — навигация по экранам и меню
├── manifest.json    — PWA-манифест
└── sw.js            — офлайн-кэширование
```
