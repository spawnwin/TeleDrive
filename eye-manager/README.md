# EYE — Football Manager

Браузерный симулятор футбольного менеджера (в духе 11x11, но современнее):
карьера, состав, 6 схем, стили игры, live-матч с полем и лентой, лига,
трансферы, тренировки, академия, инфраструктура, облачные сохранения.

**Бренд:** EYE · **UI:** тёмный Liquid Glass (iOS 26) · **язык:** русский.

Папка изолирована от мессенджера Аврора — ничего в `api/`, `web/`, `/opt/aurora` не меняет.

## Локально

```bash
cd eye-manager
node server/server.js
# http://localhost:9140
```

Или просто откройте `index.html` — локальные сохранения работают без сервера.

## VPS

```bash
cd eye-manager
sudo bash deploy/install.sh
```

- Сервис: `eye-manager` (systemd), порт **9140**
- URL: `http://<IP>:9140/` и `http://<IP>/eye/`
- Данные: `/opt/eye-manager/server/data/saves`

## Возможности

- Карьера менеджера в одной из трёх лиг EYE
- Состав до 28 игроков: OVR, потенциал, форма, травмы, голы
- Тактика: 4-3-3, 4-4-2, 4-2-3-1, 3-5-2, 5-3-2, 4-1-4-1 + 5 стилей
- Автосимуляция матчей с репортажем и canvas-полем
- Таблица лиги (дома/гости, полный календарь)
- Трансферный рынок и продажи
- Тренировки, академия, апгрейд стадиона/базы/медицины/скаутинга
- PWA + офлайн-кэш, облачное сохранение через `/api/save`
