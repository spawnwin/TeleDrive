# EYE — Football Manager

Браузерный симулятор футбольного менеджера с **реальными лигами, клубами и игроками**.

**Бренд:** EYE · **UI:** тёмный Liquid Glass (iOS 26) · **язык:** русский.

Папка изолирована от мессенджера Аврора.

## Мир

| Лига | Клубов |
|------|--------|
| Premier League | 12 |
| La Liga | 10 |
| Serie A | 10 |
| Bundesliga | 10 |
| Ligue 1 | 10 |
| РПЛ | 12 |

Всего **64 клуба**, ~**1280 игроков** (звёзды с реальными именами + добор состава), детальные статы (атака/защита/техника/пас/темп/физика/IQ).

## Карьера

- Выбор лиги → реального клуба (превью состава и бюджета)
- Календарь double round-robin, таблица, бомбардиры/ассисты
- Тактика: схемы и стили, авто-XI, live-матч
- Инфраструктура, тренировки, академия

## Трансферы

- Рынок по всем лигам мира (300+ лотов)
- Фильтры: поиск, позиция, лига, OVR, бюджет
- Покупка с переговорами / отказ / контрцена
- Аренда, продажа, входящие предложения AI-клубов
- Обновление рынка каждые 4 тура

## Навигация

| Блок | Экраны |
|------|--------|
| Команда | Центр, Состав, Тактика, Рынок |
| Сезон | Таблица, Календарь, Кубок, ЛЧ, Статистика |
| Клуб | Совет, Академия, Инфра, Финансы, Тренировка, Почта |
| Система | История, Настройки |

ПК (≥960px): боковое меню по блокам. Телефон: док + систематизированное «Меню».

## Запуск

```bash
cd eye-manager
node server/server.js
# http://localhost:9140
```

VPS: `sudo bash deploy/install.sh` → `http://IP:9140/` и `http://IP/eye/`
