# Вещевая служба ВС РФ — презентация

Презентация (28 слайдов) по системе вещевого обеспечения Вооружённых Сил Российской Федерации — в двух форматах:

| Формат | Файл |
|---|---|
| **PowerPoint (PPTX)** | [`Вещевая_служба_ВС_РФ.pptx`](./Вещевая_служба_ВС_РФ.pptx) |
| HTML (браузер) | [`index.html`](./index.html) |

## PPTX

Откройте `Вещевая_служба_ВС_РФ.pptx` в Microsoft PowerPoint, LibreOffice Impress или Google Slides.

Пересобрать из скрипта:

```bash
python3 press/veshchevaya-sluzhba/build_pptx.py
```

## HTML

Откройте файл `index.html` в браузере (двойной клик или через локальный сервер).

```bash
# из корня репозитория
python3 -m http.server 8080 --directory press/veshchevaya-sluzhba
# затем http://localhost:8080
```

## Содержание

1. Миссия и место вещевой службы в системе обеспечения  
2. Законодательство: 76-ФЗ, ПП № 390, приказ МО № 500, ГОСТ  
3. Виды имущества и категории качества  
4. ВКПО — состав, слои, порядок выдачи  
5. Сроки носки и климатические поправки  
6. Размеры, ростовка, антропометрия  
7. Специальные нормы снабжения  
8. Выдача, склад, учёт, компенсации, БПО  
9. Изменения 2024–2025  

## Источники

Обзор подготовлен по открытым редакциям:

- Федеральный закон № 76-ФЗ «О статусе военнослужащих» (ст. 14)
- Постановление Правительства РФ от 22.06.2006 № 390 (с изм., в т. ч. ПП № 1116 от 28.07.2025)
- Приказ Министра обороны РФ от 14.08.2017 № 500 (ред. от 27.06.2024)
- Приказ МО РФ от 27.06.2024 № 367
- ГОСТ 23167-91, ГОСТ 20881-91
- Распоряжение Правительства РФ от 25.05.2016 № 1014-р

Презентация носит справочно-обзорный характер; для юридически значимых решений сверяйтесь с полными текстами документов в актуальной редакции и локальными документами воинской части.
