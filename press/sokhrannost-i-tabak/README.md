# Сохранность материальных средств и табачное довольствие — ВС РФ

Один справочный HTML-слайд для доведения до личного состава:

- обязанности по сохранности материальных (военных) средств;
- норма выдачи табачной продукции и продуктовых альтернатив;
- ссылки на нормативные документы и приказы.

## Как открыть

```bash
# из корня репозитория
python3 -m http.server 8080 --directory press/sokhrannost-i-tabak
# затем http://localhost:8080
```

Либо откройте `index.html` в браузере напрямую. Для показа: F11 (полный экран).

## Что на слайде

| Блок | Содержание |
|---|---|
| Сохранность матсредств | УВС ВС РФ (Указ № 1495), 161-ФЗ, приказы МО № 300дсп / № 222дсп |
| Табачное довольствие | ПП РФ № 946: 10 сигарет/сутки + 3 коробки спичек/мес. либо сахар / карамель / сгущёнка |
| Ссылки | КонсультантПлюс, ГАРАНТ, pravo.gov.ru |

## Источники

- Указ Президента РФ от 10.11.2007 № 1495 — Устав внутренней службы ВС РФ  
- Федеральный закон от 12.07.1999 № 161-ФЗ «О материальной ответственности военнослужащих»  
- Постановление Правительства РФ от 29.12.2007 № 946 (ред. от 07.11.2025)  
- Приказ МО РФ от 15.04.2013 № 300дсп; приказ МО РФ от 28.03.2013 № 222дсп  
- Исторически: ПП РФ № 1219 (1994), приказ МО РФ № 51 (1995), приказ МО РФ № 400 прил. № 32 — утратили силу  

Слайд носит справочно-обзорный характер; для юридически значимых решений сверяйтесь с полными текстами в актуальной редакции и локальными документами воинской части.
